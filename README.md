## 👨‍💻 Engineering Overview

**Applied AI Engineer**, **AI Application Engineer**, and **Full-Stack Software Engineer** with **3+ years of hands-on experience** building and shipping production LLM applications, autonomous tool-using agents, hybrid RAG pipelines, Chrome extensions, and end-to-end web/desktop software.

- 🧠 **Agentic Systems & LLM Orchestration:** Designing deterministic **DAG task runners**, multi-agent topologies (`LangGraph`, `LangChain`, `CrewAI`), **Model Context Protocol (MCP)** servers/clients, and structured tool-calling pipelines across OpenAI, Anthropic Claude, Google Gemini, and local inference engines (`Ollama`, `vLLM`, `llama.cpp`).
- 🛡️ **Reliability, Hybrid RAG & Agent Safety:** Engineering **SQLite-backed state persistence**, crash/restart recovery, bounded retries, **4-tier risk classification kernels** with human-in-the-loop approval gates, **BM25 (FTS5) + vector cosine similarity** hybrid retrieval, and automated `pytest` evaluation suites.
- 🏗️ **End-to-End Product & Full-Stack Delivery:** Shipping full-stack SaaS applications (`Next.js`, `React 19`, `TypeScript`, `FastAPI`), native desktop utilities (`Rust/Tauri`), **Chrome Extensions (MV3)**, and containerized cloud deployments (`Docker`, `GitHub Actions`, `AWS`, `GCP`).
